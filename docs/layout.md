# Layout

## Your project

Everything sdlight reads or writes lives under `docs/sdlight/`, so
nothing lands in your project's root.

```
docs/sdlight/
  seeds/        captured ideas, one file each
  specs/        specs in progress, deleted on promotion
  plans/        implementation plans, kept as the record of how
  features/     feature docs, kept as the record of what
  templates/    copied from this repo, see Install
  SEEDS.md      map of related seeds, regenerated by sdlc-refine
  PROJECT.md    project overview, regenerated by sdlc-refine
```

Seeds and specs are temporary. They exist to become something else and
are deleted once they have. Plans and feature docs are permanent.

`PROJECT.md` is generated, except for its `phase` line, which you set by
hand. See [workflow](workflow.md#project-phase).

## This repo

```
.claude-plugin/
  plugin.json          Claude Code plugin manifest
  marketplace.json     lets /plugin marketplace add find the plugin
package.json           Pi package manifest
skills/<name>/SKILL.md the eight skills
templates/             spec, plan, feature doc, and project doc templates
extensions/            Pi extension: seed count, /seeds, /browse-seeds
scripts/diagrams.py    generates the README diagrams in docs/img/
docs/sdlight/          sdlight's own vault, from building sdlight with itself
```

Keep the `version` fields in `plugin.json` and `package.json` in sync.
